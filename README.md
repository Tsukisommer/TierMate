Simple tier list maker for movies, shows, games, anime, etc. You can search what you want to rank in the search bar and then click on the result to put it in the image inventory.
You can also import your own images to the inventory. From there, you can drag and drop your images on the tier rows to place them in whatever tier. You can re-arrange the tier labels, pick a different color, add whatever text you want or delete them if you don't need them.
You can also type under each image in case you want to add a title to the thing you're ranking. Images from the search have titles under them by default so you don't have to type anything in unless you want to change it.
You can use it by going to https://tsukisommer.github.io/TierMate/ or the releases.
